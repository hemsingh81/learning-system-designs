# Image Generation Prompts

← [Back to README](../README.md)

Copy-paste image prompts for illustrating this learning path. All images are **optional** — the text content stands on its own without them. Use these with any image-capable AI tool. Suggested filenames assume everything lives under `assets/`.

**Style consistency note:** Use the same color/style guidance across all images in one pass if generating a full set together, so the repo has a visually coherent look rather than a mismatched collage.

---

## 1. Asha Persona Portrait

**Suggested filename:** `assets/asha-portrait.png`

**Creative brief:** A professional portrait-style illustration of Asha — a senior software engineer in her early-to-mid 30s, South Asian, confident and thoughtful expression, sitting at a desk with two monitors, one showing code and one showing a chat interface. Not a literal photo — a clean, modern illustrated style.

**Color/style guidance:** Flat/semi-flat illustration style (think modern tech-company blog art), muted blue/teal/warm-neutral palette, soft even lighting, no photorealism.

## 2. Asha's Journey Timeline

**Suggested filename:** `assets/asha-journey-timeline.png`

**Creative brief:** A horizontal timeline/infographic showing Asha's arc across the 10 chapters: starting with a frustrated figure surrounded by browser tabs (left), through progressively more organized/confident poses at each learning-path milestone, ending with a calm figure at a clean desk with a single well-organized prompt catalog interface (right).

**Color/style guidance:** Same illustrated style as the portrait; use a left-to-right gradient from "cluttered/warm red-orange tones" to "organized/cool blue-green tones" to visually encode the mindset shift.

## 5. Trading Platform Architecture

**Suggested filename:** `assets/trading-architecture.png`
