## The 2-minute pitch

For "walk me through your background." It moves recent → back → forward.

> "I am a solution architect on the Microsoft stack, with nineteen years in software and the last seven owning solutions end to end — architecture, integration design, build, release, and production governance. I have spent more than a decade delivering for regulated US and UK clients in asset management, energy, healthcare and public sector.
>
> **Right now**, at TCW Group in Los Angeles, I own the design of the investment-reporting platform end to end — the application tier, the Web API layer, and the data pipeline beneath it. I architected FastAPI ETL services that ingest portfolio, position and transaction data from the BlackRock Aladdin API into SQL Server and Snowflake, with validation, retry and reconciliation. I designed a dependency-aware orchestration layer across Azure Data Factory, Tidal and Apache Airflow that lands reporting inside the pre-market window daily. And I defined a reusable controller and Web API pattern that replaced per-report bespoke code and shortened the build cycle for every new report.
>
> **On the AI side**, I authored TCW's reference architecture for connecting its applications to AI/LLM capabilities — retrieval, grounding, orchestration and evaluation — and delivered the first end-to-end implementation on it: a production RAG support assistant using LangChain, LangGraph and LangSmith over a Chroma vector database. It is now the firm's reference pattern.
>
> **Before TCW**, I was solution architect for TengizChevroil's construction-completion platform in Kazakhstan — four cloud apps on ASP.NET Core and Azure Functions, a microservices decomposition on Azure, CI/CD on Azure DevOps. That work cut manual effort by 60%, reduced processing errors by 25%, and halved release-cycle time.
>
> **What I bring** is an architect who stays through delivery and production — and who still codes. I own governance for business-critical processes, so I have run what I designed, and I wrote much of it myself: the React and Angular front ends, the ASP.NET Core Web APIs in C#, the FastAPI ETL in Python, and the T-SQL underneath. That is the difference I offer: I do not hand over a diagram and disappear — I build alongside the team and I can go as deep as any developer in the room."

## The hands-on version

For a deep-technical or coding panel — lead with the fact that I still build.

> "I am a solution architect who never stopped coding. Nineteen years on the Microsoft stack, and I still write production code across the full stack every week.
>
> On my current platform I personally built the React reporting screens, the ASP.NET Core Web APIs in C#, and the Python/FastAPI ETL services that ingest BlackRock Aladdin data — with the T-SQL and the query tuning underneath. I wrote the reusable controller and Web API pattern the whole team now reuses, and the cross-platform database utility generator for Azure SQL and Snowflake.
>
> So when you open the hood, I can go as deep as any developer in the room: write the async C#, kill the N+1, make the predicate sargable, handle the four states in the component, or wire up Entra ID auth end to end. My architecture is buildable precisely because I am the one who builds it."
